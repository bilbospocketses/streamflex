> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace StreamFlex's four per-release checklists with one smoke doc of stable, single-claim rows, a coverage register mapping every row half to its owner and evidence, per-release results files, and a required `smoke-coverage` CI check that keeps them honest.

**Architecture:** Three markdown files in `tests/qa/` (the doc, the register, a results-format README) and one standard-library Python script, `tests/qa/check-smoke.py`, with a `lint` mode (structure of all three, plus register evidence that exists in the tree) and a `gate` mode (CI: a PR that changes user-visible code updates the doc or carries a reasoned marker). A workflow of its own runs the script's unit tests, `lint` and `gate` on every PR event, including body edits.

**Tech Stack:** Python 3.12 (standard library only: `argparse`, `re`, `pathlib`, `subprocess`, `unittest`), GitHub Actions, `gh api`, Markdown.

**Spec:** `design/specs/2026-10-10-smoke-doc-design.md` (PR #53). Read it before any task; this plan argues from it.

## Global Constraints

- Paths: the doc is `tests/qa/smoke-test.md`, the register `tests/qa/automation-coverage.md`, results `tests/qa/results/vX.Y.Z.md`, the format note `tests/qa/results/README.md`, the script `tests/qa/check-smoke.py`, its tests `tests/qa/test_check_smoke.py`, the workflow `.github/workflows/smoke-coverage.yml`. Nothing under `docs/` (the published Pages site).
- Id grammar, exactly: `<module>.<n>`, optionally followed by ONE lowercase letter (`5.3a`) OR `-` plus `[a-z][a-z0-9-]*` (`4.2-system-gui`), never both. Regex `\d+\.\d+(?:[a-z]|-[a-z][a-z0-9-]*)?`, full match.
- Anchor: `t-` plus the id with `.` written as `-` (`5.3a` → `t-5-3a`, `4.2-system-gui` → `t-4-2-system-gui`).
- Row line: `| ☐ <a id="t-3-2"></a> **3.2** `[All]` <name> | <steps> | <expected> |`, exactly three cells; a literal `|` inside a cell is written `\|`.
- Nine tags, exactly one per row: `[Win]`, `[Ubuntu]`, `[Kubuntu]`, `[Fedora]`, `[Fedora-KDE]`, `[GNOME]` = Ubuntu + Fedora, `[KDE]` = Kubuntu + Fedora-KDE, `[Linux]` = the four Linux desktops, `[All]` = all five.
- Register line: `| Row | Platforms | Owner | Where it runs, or why not |`. Owners: `streamflex-ctest`, `streamflex-headless`, `qa-harness`, `manual`. No `qa-harness` owner exists anywhere in this build: item 75 has named no arc yet, so every half that lane will run is `manual` with `qa-harness item 75, planned` in the last column.
- Results cells: `x`, `F<n>`, `S<n>`, `-`, `x (vA.B.C)`; an empty cell is never a pass; `F<n>` needs a `## Findings` entry and `S<n>` a `## Not measured` entry, each written `- **F1** ...`.
- Gate marker: `<!-- smoke: none -- <reason> -->`; an empty reason fails.
- Watched paths: `src/` (except `src/test_hooks.c`, `src/test_hooks.h`), `assets/`, `config/`, root `CMakeLists.txt`, `vcpkg.json`.
- The script uses only the standard library and runs on Python 3.12 (CI) and 3.13 (the dev box). It never prints the `☐` character in a message, and reconfigures stdout and stderr with `errors="replace"`, so a Windows console in a legacy code page cannot crash it.

```python
#!/usr/bin/env python3
"""The smoke doc's lint and its PR gate.

  python tests/qa/check-smoke.py lint                      check the doc, the register and the results files
  python tests/qa/check-smoke.py lint --write              also regenerate the register's summary block
  python tests/qa/check-smoke.py lint --complete FILE ...  also require those results files to cover every row
  python tests/qa/check-smoke.py gate                      CI only: see gate() below

Design: design/specs/2026-10-10-smoke-doc-design.md
"""

import argparse
import re
import sys
from pathlib import Path
from typing import NamedTuple

ROOT = Path(__file__).resolve().parents[2]
DOC = "tests/qa/smoke-test.md"
REGISTER = "tests/qa/automation-coverage.md"
RESULTS_DIR = "tests/qa/results"

DESKTOPS = ("Win", "Ubuntu", "Kubuntu", "Fedora", "Fedora-KDE")
TAGS = {
    "Win": frozenset({"Win"}),
    "Ubuntu": frozenset({"Ubuntu"}),
    "Kubuntu": frozenset({"Kubuntu"}),
    "Fedora": frozenset({"Fedora"}),
    "Fedora-KDE": frozenset({"Fedora-KDE"}),
    "GNOME": frozenset({"Ubuntu", "Fedora"}),
    "KDE": frozenset({"Kubuntu", "Fedora-KDE"}),
    "Linux": frozenset({"Ubuntu", "Kubuntu", "Fedora", "Fedora-KDE"}),
    "All": frozenset(DESKTOPS),
}
OWNERS = ("streamflex-ctest", "streamflex-headless", "qa-harness", "manual")
AUTOMATED = ("streamflex-ctest", "streamflex-headless", "qa-harness")

# qa-harness parses ids with the same grammar, so the two must agree byte for byte
ID = r"\d+\.\d+(?:[a-z]|-[a-z][a-z0-9-]*)?"
ID_RE = re.compile(rf"^{ID}$")
TAG_RE = re.compile(r"`\[([^\]`]*)\]`")
ROW_START = "| \u2610"
ROW_RE = re.compile(r'^\| \u2610 <a id="([^"]*)"></a> \*\*([^*]+)\*\* ')
ROW_SHAPE = '| [box] <a id="t-..."></a> **<id>** `[<tag>]` <name> | <steps> | <expected> |'


class Row(NamedTuple):
    id: str
    tag: "str | None"
    line: int


def cells(line):
    """The cells of a markdown table line. An escaped pipe (\\|) stays inside its cell."""
    parts = re.split(r"(?<!\\)\|", line.strip())
    return [p.strip() for p in parts[1:-1]]


def anchor_for(row_id):
    return "t-" + row_id.replace(".", "-")


def parse_doc(text):
    """Return (rows, retired, errors). Rows are lines that start with '| <box>'; retired ids are
    the '- <id>' lines under '## Retired ids'."""
    rows, retired, errors = [], [], []
    section = None
    for n, line in enumerate(text.splitlines(), 1):
        if line.startswith("## "):
            section = line[3:].strip()
            continue
        if section == "Retired ids":
            m = re.match(rf"^- ({ID})(?=\s|$)", line)
            if m:
                retired.append((m.group(1), n))
            elif line.startswith("- "):
                errors.append(f"{DOC}:{n}: a retired-ids entry must start with a valid id")
            continue
        if not line.startswith(ROW_START):
            continue
        m = ROW_RE.match(line)
        if not m or not line.rstrip().endswith("|"):
            errors.append(f"{DOC}:{n}: a row must read {ROW_SHAPE}")
            continue
        anchor, rid = m.groups()
        if not ID_RE.match(rid):
            errors.append(f"{DOC}:{n}: {rid!r} is not a valid id (<module>.<n>, then one lowercase letter or -word)")
            continue
        if anchor != anchor_for(rid):
            errors.append(f'{DOC}:{n}: anchor "{anchor}" should be "{anchor_for(rid)}"')
        row_cells = cells(line)
        if len(row_cells) != 3:
            errors.append(f"{DOC}:{n}: row {rid} has {len(row_cells)} cells, not three cells; write a literal pipe as \\|")
        tags = TAG_RE.findall(row_cells[0]) if row_cells else []
        tag = tags[0] if len(tags) == 1 and tags[0] in TAGS else None
        if tag is None:
            errors.append(f"{DOC}:{n}: row {rid} needs exactly one tag from {', '.join('[' + t + ']' for t in TAGS)}")
        rows.append(Row(rid, tag, n))
    return rows, retired, errors


def lint_doc(rows, retired):
    errors = []
    seen = {}
    for r in rows:
        if r.id in seen:
            errors.append(f"{DOC}:{r.line}: {r.id} appears more than once (first at line {seen[r.id]})")
        else:
            seen[r.id] = r.line
    retired_ids = {rid for rid, _ in retired}
    for r in rows:
        if r.id in retired_ids:
            errors.append(f"{DOC}:{r.line}: {r.id} is retired and can never be reused; give the row a new id")
    return errors


def run_lint(root, write=False, complete=()):
    """Every lint error in the tree at root, as a list of messages."""
    doc_path = root / DOC
    if not doc_path.is_file():
        return [f"{DOC}: missing"]
    rows, retired, errors = parse_doc(doc_path.read_text(encoding="utf-8"))
    errors += lint_doc(rows, retired)
    return errors


def main(argv=None):
    for stream in (sys.stdout, sys.stderr):
        if hasattr(stream, "reconfigure"):
            stream.reconfigure(errors="replace")
    parser = argparse.ArgumentParser(description="The smoke doc's lint and its PR gate.")
    sub = parser.add_subparsers(dest="mode", required=True)
    lint = sub.add_parser("lint", help="check the doc, the register and the results files")
    lint.add_argument("--write", action="store_true", help="regenerate the register's summary block")
    lint.add_argument("--complete", nargs="+", default=[], metavar="FILE",
                      help="results files that must cover every row of the doc")
    args = parser.parse_args(argv)
    if args.mode == "lint":
        errors = run_lint(ROOT, write=args.write, complete=args.complete)
        for e in errors:
            print(e, file=sys.stderr)
        if errors:
            print(f"smoke lint: {len(errors)} error(s)", file=sys.stderr)
            return 1
        print("smoke lint OK")
        return 0
    return 2


if __name__ == "__main__":
    sys.exit(main())
```

```python
    out = ["# Automation coverage", ""]
    out += [summary_block] if summary_block is not None else [cs.SUMMARY_BEGIN, cs.SUMMARY_END]
```

```python
def parse_register(text):
    """Return (halves, errors) from the table under '## Every row'."""
    halves, errors = [], []
    section = None
    for n, line in enumerate(text.splitlines(), 1):
        if line.startswith("## "):
            section = line[3:].strip()
            continue
        if section != "Every row" or not line.startswith("|"):
            continue
        c = cells(line)
        if not c or c[0] == "Row" or set(c[0]) <= set("-: "):
            continue
        if len(c) != 4:
            errors.append(f"{REGISTER}:{n}: a register line has four cells (Row, Platforms, Owner, Where); write a literal pipe as \\|")
            continue
        rid, platforms, owner, where = c
        if not ID_RE.match(rid):

            continue

            errors.append(f"{REGISTER}:{n}: {rid}: 'Where it runs, or why not' is empty")
        halves.append(Half(rid, tag, owner, where, n))
```

```python
def run_lint(root, write=False, complete=()):
    """Every lint error in the tree at root, as a list of messages."""
```

```python
def parse_results(text, path):
    """Return (table, errors). table maps a row id to (its five cells, its line). Only the table
    under RESULTS_HEADER is read; the header's own tables (desktops, images) are not results."""
    table, entries, errors = {}, {}, []
    section, in_table, header_seen = None, False, False
    for n, line in enumerate(text.splitlines(), 1):
        if line.startswith("## "):
            section, in_table = line[3:].strip(), False
            continue
        if section in ENTRY_SECTION.values():
            m = ENTRY_RE.match(line)
            if m:
                eid = m.group(1)
                if section != ENTRY_SECTION[eid[0]]:
                    errors.append(f"{path}:{n}: {eid} belongs under ## {ENTRY_SECTION[eid[0]]}")
                elif eid in entries:
                    errors.append(f"{path}:{n}: {eid} has two entries")
                entries[eid] = section
            continue
        if line.startswith("| Row |"):
            header_seen = in_table = True
            if line.strip() != RESULTS_HEADER:
                errors.append(f"{path}:{n}: the results table's header must be exactly {RESULTS_HEADER}")
            continue
        if not in_table:
            continue
        if not line.startswith("|"):
            in_table = False
            continue
        c = cells(line)
        if c and set(c[0]) <= set("-: "):
            continue
        if len(c) != 6 or not ID_RE.match(c[0]):
            errors.append(f"{path}:{n}: a results line is | <id> | Win | Ubuntu | Kubuntu | Fedora | Fedora-KDE |")
            continue
        if c[0] in table:
            errors.append(f"{path}:{n}: {c[0]} appears more than once")
        for desktop, cell in zip(DESKTOPS, c[1:]):
            if cell and not CELL_RE.match(cell):
                errors.append(f"{path}:{n}: {c[0]}: {desktop}: {cell!r} is not a results cell (x, F<n>, S<n>, -, x (vA.B.C))")
        table[c[0]] = (c[1:], n)
    if not header_seen:
        errors.append(f"{path}: no results table (its header is {RESULTS_HEADER})")
    for rid, (row_cells, n) in table.items():
        for cell in row_cells:
            if re.match(r"^[FS][1-9]\d*$", cell) and entries.get(cell) != ENTRY_SECTION[cell[0]]:
                errors.append(f"{path}:{n}: {cell} has no entry under ## {ENTRY_SECTION[cell[0]]}")
    return table, errors


def lint_results(path, table, rows, retired, complete):
    """Form checks for every results file; completeness only for the files a PR adds or changes."""
    errors = []
    by_id = {r.id: r for r in rows}
    retired_ids = {rid for rid, _ in retired}
    for rid, (row_cells, n) in table.items():
        if rid not in by_id and rid not in retired_ids:
            errors.append(f"{path}:{n}: {rid} is not a row of the smoke doc")
            continue
        r = by_id.get(rid)
        if r is None or r.tag is None:
            continue
        for desktop, cell in zip(DESKTOPS, row_cells):
            inside = desktop in TAGS[r.tag]
            if cell == "-" and inside:
                errors.append(f"{path}:{n}: {rid}: {desktop} is inside the row's tag [{r.tag}]; it needs a verdict, not -")
            elif complete and inside and not cell:
                errors.append(f"{path}:{n}: {rid}: {desktop} is empty")
            elif complete and not inside and cell != "-":
                errors.append(f"{path}:{n}: {rid}: {desktop} is outside the row's tag [{r.tag}]; write -")
    if complete:
        for r in rows:
            if r.id not in table:
                errors.append(f"{path}: {r.id} has no line")
    return errors
```

```markdown
   **Desktop** is `Win`, `Ubuntu`, `Kubuntu`, `Fedora` or `Fedora-KDE`; **OS** the OS and version; **Image** qa-harness's base image digest when it ran that desktop, else `-`; **Build** the installed artifact's sha256, plus the CI run id on the Fedoras (`sha256:… (run 38…)`). qa-harness's renderer emits these lines. A patch release that carries rows forward says once, here, why its change cannot affect them.
2. **Results table**, with exactly this header:

   | Row | Win | Ubuntu | Kubuntu | Fedora | Fedora-KDE |
   |---|---|---|---|---|---|

   One line per row id. A cell is one of:

   | Cell | Means |
   |---|---|
   | `x` | pass |
   | `F1` | fail; its write-up is `F1` under Findings |
   | `S1` | not measured; its reason is `S1` under Not measured |
   | `-` | the desktop is outside the row's tag |
   | `x (v0.5.0)` | carried forward from that release's pass (patch releases only) |

   An empty cell is never a pass. A skip's reason never goes in the cell: reasons are long and often hold a `|`.
3. **`## Findings`**: `- **F1** <what failed, what was seen, the log or frame, and the fix PR or patch release, or the user's decision to ship with it>`.
4. **`## Not measured`**: `- **S1** <the full reason, verbatim from qa-harness's NOT MEASURED text where it came from there, and where it was measured afterwards or the user's decision to ship with it>`.

## Who fills which cells

- **qa-harness halves:** pasted from the fragment qa-harness renders from its run record and hands over through ClaudeScratch. qa-harness never pushes to this repo.
- **`streamflex-headless` and `streamflex-ctest` halves:** `x` from the release commit's green `build-and-test` run.
- **`manual` halves:** whoever runs the pass by hand.

## What holds a release

Any `F` or `S` inside a row's tag. A fail is fixed and a skip is measured first, or the user decides to ship with it and its entry records that.

## Checking a file

    python tests/qa/check-smoke.py lint --complete tests/qa/results/vX.Y.Z.md

`--complete` requires a line for every row of the doc and no empty cell inside a row's tag. CI runs it on every results file a PR adds or changes. Every other results file is checked for form only, so a committed file stays as it was when its release shipped.
```

```python
def is_watched(path):
    return path not in UNWATCHED and (path in WATCHED_FILES or path.startswith(WATCHED_PREFIXES))


def parse_opt_out(body):
    """The marker's reason, '' for a marker with an empty reason, or None for no marker."""
    m = MARKER_RE.search(body or "")
    return None if m is None else m.group(1).strip()


def evaluate(files, body):
    """The gate's decision as data: (verdict, watched files, reason)."""
    watched = [f for f in files if is_watched(f)]
    if not watched:
        return "not-applicable", watched, None
    if DOC in files:
        return "smoke-doc-updated", watched, None
    reason = parse_opt_out(body)
    if reason:
        return "opted-out", watched, reason
    return ("empty-reason" if reason == "" else "missing"), watched, None


def changed_results(entries):
    """The results files a PR adds or changes, from its (status, filename) pairs."""
    return [f for status, f in entries if status != "removed" and RESULTS_NAME_RE.match(f)]


def gh(args):
    return subprocess.run(["gh", *args], check=True, stdout=subprocess.PIPE, text=True, encoding="utf-8").stdout


def gate():
    """CI: a PR that changes user-visible code updates the smoke doc or says why not in its body,
    and every results file it adds or changes covers every row. The body is read live through the
    API, not from the event payload, so re-running after a body edit sees the edit."""
    repo, pr = os.environ.get("GITHUB_REPOSITORY"), os.environ.get("PR_NUMBER")
    if not repo or not pr:
        print("smoke gate: GITHUB_REPOSITORY and PR_NUMBER must be set", file=sys.stderr)
        return 2
    rows = gh(["api", "--paginate", f"repos/{repo}/pulls/{pr}/files",
               "--jq", '.[] | [.status, .filename, (.previous_filename // "")] | @tsv'])
    entries, files = [], []
    for line in rows.splitlines():
        status, filename, previous = (line.split("\t") + ["", "", ""])[:3]
        entries.append((status, filename))
        files += [filename] + ([previous] if previous else [])
    body = gh(["api", f"repos/{repo}/pulls/{pr}", "--jq", '.body // ""'])
    verdict, watched, reason = evaluate(files, body)
    failed = False
    if verdict == "not-applicable":
        print("smoke gate: no user-visible change -- nothing to decide")
    elif verdict == "smoke-doc-updated":
        print(f"smoke gate OK -- {DOC} is updated in this PR")
    elif verdict == "opted-out":
        # PR-body text goes out as data, never as a format string
        print("smoke gate OK -- opted out with a reason:", json.dumps(reason))
    else:
        failed = True
        shown = "\n".join(f"    - {f}" for f in watched[:20])
        more = f"\n    - ... and {len(watched) - 20} more" if len(watched) > 20 else ""
        empty = ("The PR body has a smoke: none marker, but its reason is empty, and a marker with no reason "
                 "does not count.\n\n") if verdict == "empty-reason" else ""
        print(f"This PR changes code a user can see, and {DOC} is untouched:\n{shown}{more}\n\n{empty}"
              f"Decide one of:\n  - add or update the rows in {DOC} that cover the change, or\n"
              "  - put this in the PR body, with the real reason:\n"
              "        <!-- smoke: none -- <why this change has no smoke impact> -->\n\n"
              "Editing the PR body re-runs this check on its own.", file=sys.stderr)
    complete = changed_results(entries)
    errors = run_lint(ROOT, complete=[str(ROOT / f) for f in complete])
    for e in errors:
        print(e, file=sys.stderr)
    if complete and not errors:
        print("smoke gate OK -- complete:", ", ".join(complete))
    return 1 if failed or errors else 0
```
