# The SDL3 port, Vulkan first: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move StreamFlex from SDL2, SDL2_image and SDL2_ttf to SDL3, SDL3_image and SDL3_ttf, ask for Vulkan first, recover a lost GPU device, and take the spec's five additions, shipping alone as v0.5.0.

**Architecture:** This plan is written in two stages, as the spec requires (§ 3, § 8). **Phase 0** runs two gates before any port task is written: the Transparent spike, a throwaway SDL3 program that applies StreamFlex's chroma key under each renderer, and the timing measurement, a throwaway SDL2 patch on master that logs where icon and background loading spends its time. **Phase 1 onward** (the port itself) is written only after both gates have reported to the user, because a failed spike or a tripped threshold changes what those tasks build. Nothing from Phase 0 is merged.

**Tech Stack:** C (MSVC `/W4 /WX` on Windows, gcc on Linux), SDL2 2.0.18+ (Phase 0's timing patch), SDL3 3.4.12 from vcpkg (Phase 0's spike), CMake, vcpkg at `9e593bb`, Docker (the headless harness image), PowerShell 7, ImageMagick, GitHub Actions (`workflow_dispatch`).

**Spec:** `design/specs/2026-10-06-sdl3-port-design.md` (PR #42, `dd30307`). Read it in full before any task; this plan argues from it. Research behind it: `C:/Users/jscha/ClaudeScratch/streamflex-sdl3-research/`.

## Global Constraints

- **Version floors** (spec § 2): SDL3 **3.2.10**, SDL3_image **3.2.4**, SDL3_ttf **3.2.2**. Debian and the Pi build at the floor; Arch and Windows at the newest. Code that compiles only on 3.4 fails CI.
- **Renderer preference lists** (spec § 3): Windows `"vulkan,direct3d12,direct3d11,opengl"`, Linux and Pi `"vulkan,opengl"`. When `SDL_RENDER_DRIVER` is set, pass no list.
- **Platforms** (spec, Decisions): Debian trixie, Raspberry Pi OS trixie, Ubuntu 25.10, Arch, Windows, or newer. v0.4.1 is the last release for Debian bookworm and Ubuntu 24.04 LTS. No backport.

```c
// Timing patch (throwaway, never merged): what icon loading spent, summed by render_buttons
Uint64 timing_read = 0, timing_decode = 0, timing_texture = 0;

// Timing patch: whole milliseconds from performance-counter counts
unsigned timing_ms(Uint64 counts)
{
    Uint64 frequency = SDL_GetPerformanceFrequency();
    return (unsigned) ((counts * 1000 + frequency / 2) / frequency);
}

// Timing patch: IMG_Load in two timed parts, the read and the decode, the way IMG_Load does it
// (the file's extension is the type hint)
static SDL_Surface *timed_load(const char *path, Uint64 *read, Uint64 *decode)
{
    Uint64 start = SDL_GetPerformanceCounter();
    size_t size = 0;
    void *data = SDL_LoadFile(path, &size);
    Uint64 loaded = SDL_GetPerformanceCounter();
    *read += loaded - start;
    if (data == NULL)
        return NULL;
    const char *dot = SDL_strrchr(path, '.');
    SDL_Surface *surface = IMG_LoadTyped_RW(SDL_RWFromConstMem(data, (int) size), 1, dot != NULL ? dot + 1 : NULL);
    SDL_free(data);
    *decode += SDL_GetPerformanceCounter() - loaded;
    return surface;
}
```

```c
// window the way StreamFlex does (no graphics flag), creates a renderer from StreamFlex's Windows
// preference list, or from SDL_RENDER_DRIVER when that is set, and draws the default chroma key
// (#010101) with a gray square in the middle and a red bar along the bottom. Transparent is
// StreamFlex's own call: WS_EX_LAYERED plus SetLayeredWindowAttributes(..., LWA_COLORKEY), applied
// after the renderer exists, as reload_background() applies it.
//   spike.exe           Transparent from the start
//   spike.exe --live    opaque (dark blue) for 3 s, then Transparent switches on, as from settings
//   spike.exe --drivers print the render drivers this SDL has and quit, with no window
// T toggles Transparent, Esc quits, and it quits by itself after 60 s.
#define WIN32_LEAN_AND_MEAN
#include <windows.h>
#include <stdarg.h>
#include <stdbool.h>
#include <stdio.h>
#include <string.h>
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>

#define KEY_R 0x01
#define KEY_G 0x01
#define KEY_B 0x01
#define PREFERENCE "vulkan,direct3d12,direct3d11,opengl"
#define QUIT_AFTER_MS 60000
#define LIVE_SWITCH_MS 3000
#define PROBE_AFTER_MS 2000

static FILE *log_file = NULL;

static void say(const char *format, ...)
{
    char line[1024];
    va_list args;
    va_start(args, format);
    vsnprintf(line, sizeof(line), format, args);
    va_end(args);
    printf("%s\n", line);
    fflush(stdout);
    if (log_file != NULL) {
        fprintf(log_file, "%s\n", line);
        fflush(log_file);
    }
}

// Read the HWND now: the OpenGL renderer may have replaced the native window (spec section 3)
static HWND window_hwnd(SDL_Window *window)
{
    return (HWND) SDL_GetPointerProperty(SDL_GetWindowProperties(window), SDL_PROP_WINDOW_WIN32_HWND_POINTER, NULL);
}

static void set_transparent(HWND hwnd, bool on)
{
    LONG style = GetWindowLong(hwnd, GWL_EXSTYLE);
    if (on) {
        SetWindowLong(hwnd, GWL_EXSTYLE, style | WS_EX_LAYERED);
        if (!SetLayeredWindowAttributes(hwnd, RGB(KEY_R, KEY_G, KEY_B), 0, LWA_COLORKEY))
            say("SetLayeredWindowAttributes failed: error %lu", GetLastError());
    }
    else
        SetWindowLong(hwnd, GWL_EXSTYLE, style & ~WS_EX_LAYERED);
    say("Transparent: %s (HWND %p)", on ? "on" : "off", (void *) hwnd);
}

// Read two pixels of the screen as the desktop composes it: a corner, where the key is drawn, and
// the center, inside the gray square. A see-through corner shows whatever is behind the window.
// A helper only: what the person sees decides.
static void probe(void)
{
    HDC screen = GetDC(NULL);
    HDC memory = CreateCompatibleDC(screen);
    int width = GetSystemMetrics(SM_CXSCREEN), height = GetSystemMetrics(SM_CYSCREEN);
    HBITMAP bitmap = CreateCompatibleBitmap(screen, width, height);
    HGDIOBJ previous = SelectObject(memory, bitmap);
    BitBlt(memory, 0, 0, width, height, screen, 0, 0, SRCCOPY | CAPTUREBLT);
    COLORREF corner = GetPixel(memory, 40, 40);
    COLORREF center = GetPixel(memory, width / 2, height / 2);
    SelectObject(memory, previous);
    DeleteObject(bitmap);
    DeleteDC(memory);
    ReleaseDC(NULL, screen);
    bool keyed = GetRValue(corner) == KEY_R && GetGValue(corner) == KEY_G && GetBValue(corner) == KEY_B;
    bool solid = GetRValue(center) == 0x80 && GetGValue(center) == 0x80 && GetBValue(center) == 0x80;
    say("Probe: corner #%02X%02X%02X (%s), center #%02X%02X%02X (%s)",
        GetRValue(corner), GetGValue(corner), GetBValue(corner), keyed ? "the key color" : "see-through",
        GetRValue(center), GetGValue(center), GetBValue(center), solid ? "solid" : "NOT the square");
}

static void draw(SDL_Renderer *renderer, bool transparent, int width, int height)
{
    if (transparent)
        SDL_SetRenderDrawColor(renderer, KEY_R, KEY_G, KEY_B, 255);
    else
        SDL_SetRenderDrawColor(renderer, 0x1E, 0x2A, 0x44, 255);
    SDL_RenderClear(renderer);
    SDL_FRect square = { (float) (width / 2 - 200), (float) (height / 2 - 200), 400.0f, 400.0f };
    SDL_SetRenderDrawColor(renderer, 0x80, 0x80, 0x80, 255);
    SDL_RenderFillRect(renderer, &square);
    SDL_FRect bar = { 0.0f, (float) (height - 60), (float) width, 60.0f };
    SDL_SetRenderDrawColor(renderer, 0xC0, 0x00, 0x00, 255);
    SDL_RenderFillRect(renderer, &bar);
    SDL_RenderPresent(renderer);
}

int main(int argc, char *argv[])
{
    bool live = argc > 1 && strcmp(argv[1], "--live") == 0;
    bool drivers_only = argc > 1 && strcmp(argv[1], "--drivers") == 0;
    char path[MAX_PATH];
    snprintf(path, sizeof(path), "%sspike.log", SDL_GetBasePath());
    log_file = fopen(path, "w");

    SDL_SetAppMetadata("StreamFlex SDL3 spike", "0", "streamflex-spike");
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        say("SDL_Init failed: %s", SDL_GetError());
        return 3;
    }
    int version = SDL_GetVersion();
    say("SDL %d.%d.%d", SDL_VERSIONNUM_MAJOR(version), SDL_VERSIONNUM_MINOR(version), SDL_VERSIONNUM_MICRO(version));
    for (int i = 0; i < SDL_GetNumRenderDrivers(); i++)
        say("Render driver available: %s", SDL_GetRenderDriver(i));
    if (drivers_only) {
        SDL_Quit();
        return 0;
    }

    SDL_Window *window = SDL_CreateWindow("StreamFlex SDL3 spike", 1280, 720, SDL_WINDOW_FULLSCREEN);
    if (window == NULL) {
        say("Window: none: %s", SDL_GetError());
        SDL_Quit();
        return 3;
    }
    const char *forced = SDL_getenv("SDL_RENDER_DRIVER");
    SDL_Renderer *renderer = SDL_CreateRenderer(window, forced != NULL ? NULL : PREFERENCE);
    if (renderer == NULL) {
        say("Renderer: none (%s): %s", forced != NULL ? forced : PREFERENCE, SDL_GetError());
        SDL_DestroyWindow(window);
        SDL_Quit();
        return 2;
    }
    say("Renderer: %s%s", SDL_GetRendererName(renderer), forced != NULL ? " (from SDL_RENDER_DRIVER)" : "");
    SDL_SetRenderVSync(renderer, 1);
    int width = 0, height = 0;
    SDL_GetWindowSizeInPixels(window, &width, &height);
    say("Screen: %dx%d px, pixel density %.2f, display scale %.2f", width, height,
        SDL_GetWindowPixelDensity(window), SDL_GetWindowDisplayScale(window));
    say("Mode: %s", live ? "live (opaque now, Transparent in 3 s)" : "startup (Transparent from the start)");

    bool transparent = !live, switched_live = !live, probed = false, running = true;
    if (transparent)
        set_transparent(window_hwnd(window), true);
    Uint64 start = SDL_GetTicks(), changed = start;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_EVENT_QUIT || (event.type == SDL_EVENT_KEY_DOWN && event.key.key == SDLK_ESCAPE))
                running = false;
            else if (event.type == SDL_EVENT_KEY_DOWN && event.key.key == SDLK_T && !event.key.repeat) {
                transparent = !transparent;
                set_transparent(window_hwnd(window), transparent);
                changed = SDL_GetTicks();
                probed = false;
            }
            else if (event.type == SDL_EVENT_WINDOW_FOCUS_GAINED) {
                say("Focus: gained");
                changed = SDL_GetTicks();
                probed = false;
            }
            else if (event.type == SDL_EVENT_WINDOW_FOCUS_LOST)
                say("Focus: lost");
            else if (event.type == SDL_EVENT_RENDER_TARGETS_RESET || event.type == SDL_EVENT_RENDER_DEVICE_RESET ||
                     event.type == SDL_EVENT_RENDER_DEVICE_LOST)
                say("Render event: 0x%X", (unsigned) event.type);
        }
        Uint64 now = SDL_GetTicks();
        if (!switched_live && now - start >= LIVE_SWITCH_MS) {
            switched_live = true;
            transparent = true;
            set_transparent(window_hwnd(window), true);
            changed = now;
            probed = false;
        }
        if (transparent && !probed && now - changed >= PROBE_AFTER_MS) {
            probe();
            probed = true;
        }
        if (now - start >= QUIT_AFTER_MS) {
            say("Quit: 60 s passed");
            running = false;
        }
        if (running)
            draw(renderer, transparent, width, height);
    }
    say("Quit");
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    if (log_file != NULL)
        fclose(log_file);
    return 0;
}
```

## Phase 0 results

### The Transparent spike (user's runs 1-5, 2026-10-10; RTX 3060, 3840x2160 at 175%)

| Renderer | Chroma key (`LWA_COLORKEY`) | Per-pixel alpha, fullscreen | Per-pixel alpha, not promotable |
|---|---|---|---|
| direct3d (D3D9) | works | fails | - |
| direct3d11 | fails | works | - |
| direct3d12 | fails | refused by SDL | - |
| opengl | fails | fails | works |
| vulkan, stock SDL 3.4.12 | fails | fails (black) | - |
| vulkan, SDL patched | - | fails | works (centered window; one row short with the taskbar marked; one row taller) |

- **The chroma key fails** under every SDL3 renderer but D3D9: SDL3's D3D11 and D3D12 present with flip-model swapchains, which a layered window's color key never sees.
- **Per-pixel alpha** is `SDL_WINDOW_TRANSPARENT` (DWM blur-behind, `video/windows/SDL_windowswindow.c:759-776`). D3D12 refuses it (`SDL_render_d3d12.c:3499-3502`); D3D11 switches to `DXGI_SWAP_EFFECT_DISCARD` for it (`SDL_render_d3d11.c:887-891`). SDL 3.4.12's Vulkan renderer sets `compositeAlpha` to 0 for it (`SDL_render_vulkan.c:2297`), which is not a valid mode, though this NVIDIA driver offers `PRE_MULTIPLIED` (`vulkaninfo`).
- **Independent flip hid the rest:** a window exactly covering the display skips DWM's composition, so its alpha never reached the screen while a GDI capture still showed the desktop through it. A window one row short or one row taller is not promoted.

**Decision (user, 2026-10-10):** Transparent on Windows uses per-pixel alpha on the list `"vulkan,direct3d11"`. Choosing Transparent recreates the window with `SDL_WINDOW_TRANSPARENT`, one pixel row short of the display and marked fullscreen with `ITaskbarList2::MarkFullscreenWindow`, so the taskbar goes behind it. Every other background keeps true fullscreen on the Vulkan-first list. The SDL3 Vulkan renderer fix (choose `PRE_MULTIPLIED`, then `POST_MULTIPLIED`, then `INHERIT` from `supportedCompositeAlpha`, and fail otherwise so the list falls to direct3d11) rides in the Windows vcpkg overlay port beside the SDL3_ttf fix, and is sent upstream. The spec is amended before Phase 1 is written (§ 3 Transparent and device loss, Decisions, Out of scope, § 9).
